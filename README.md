# 粮仓物联网监测与控制系统

基于 STM32F407ZG + FreeRTOS + LVGL 的温室/农业环境监测与控制系统。

## 项目介绍

本项目面向智慧农业场景，实现对温室大棚或户外农田环境的实时监测与远程控制。
系统以 STM32F407ZG 微控制器为核心，集成多种环境传感器与执行器，配合
LVGL 触控界面与 FreeRTOS 实时调度，提供完整的"感知 → 决策 → 执行"闭环。

支持本地触控控制、LoRa 远程控制、MQTT 网络上报三种方式，可灵活部署
在不同规模的应用场景中。

## 功能

### 环境监测

- 温度与湿度采集（DHT11）
- 雨量检测（FC37 雨滴传感器）
- CO₂ 浓度监测（SPG30）
- CO 浓度监测（MQ7）

### 执行器控制

- 风扇调速：4 档可调（OFF / LOW / MID / HI）
- 加热器开关
- 加湿器开关
- 控制来源支持：本地 GUI / LoRa 远程 / MQTT 网络 / 自动阈值

### 人机界面（LVGL）

- 实时数据展示
- 多周期历史曲线（30 分钟 / 60 分钟 / 12 小时 / 24 小时）
- 风扇 / 加热 / 加湿 手动控制
- FreeRTOS 任务状态与内存监控

### 远程通信

- **LoRa 无线**：4 字节帧协议，支持远程控制指令下行
- **MQTT 网络**：定时上报环境数据，支持 JSON 控制指令下行
- **多源控制统一调度**：所有控制信号汇聚到同一队列处理

### 系统保障

- 独立看门狗（IWDG）：20 秒超时，防止系统死机
- 30 秒阶段超时保护：MQTT 状态机卡死自动重置
- 队列满丢弃策略：核心任务永不阻塞
